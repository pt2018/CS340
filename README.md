# CS340

Writing Maintainable and Readable Programs

I write programs that are easier to maintain by using clear names, adding helpful comments, and separating code based on what it does. In Project One, I created a CRUD Python module to handle database operations. I reused that module in Project Two to connect the dashboard to MongoDB. This helped because I could work on the dashboard without rewriting the database connection and queries each time. Keeping the database operations together also made it easier to find problems and make changes. In the future, I could reuse this module in another dashboard or application that needs to create, read, update, or delete animal records.

Approaching Problems as a Computer Scientist

I approach a problem by breaking it into smaller tasks and checking the requirements as I go. For Grazioso Salvare, I started with the database connection and then worked on the table, rescue filters, and charts. I used the dashboard specifications to decide which breeds, ages, and sexes each filter should include. This project differed from previous assignments because I had to connect several parts into one application for a specific client. In the future, I would first clarify the client's needs, review the available data, and test queries before connecting them to the interface. I would also check for missing information and empty results early in development.

Why Computer Science Matters

Computer scientists use technology to solve problems and make tasks easier to complete. Their work includes understanding what users need, organizing information, building software, and testing that it works correctly. A dashboard like this could help Grazioso Salvare spend less time searching through animal records by bringing matching dogs into one view. The filters, table, and map give staff a starting point for finding dogs to evaluate for rescue training. This shows how software can support the work of an organization and help people make better use of their data.
